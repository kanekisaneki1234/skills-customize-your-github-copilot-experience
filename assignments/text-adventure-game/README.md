# 📘 Assignment: Text Adventure Game

## 🎯 Objective

Build an interactive text-based adventure game where the player moves through rooms, makes choices, and manages inventory or health while reaching a goal.

## 📝 Tasks

### 🛠️ Set Up the Game World

#### Description
Create a simple game map with multiple rooms and a starting location for the player.

#### Requirements
Completed program should:

- Create at least three rooms or locations.
- Store room information in a dictionary or list.
- Show the player's current room and available actions.
- Display a friendly introduction when the game begins.

### 🛠️ Add Player Choices

#### Description
Let the player choose what to do next as they explore the game.

#### Requirements
Completed program should:

- Ask the player for a command or choice.
- Support choices such as move, look, take item, and quit.
- Use conditionals to respond based on the player's input.
- Keep the game running until the player wins or exits.

### 🛠️ Include Game State and Win Conditions

#### Description
Add inventory, health, or score tracking so the game feels complete and interactive.

#### Requirements
Completed program should:

- Track at least one item or stat such as inventory, keys, or health.
- Use functions to organize repeated game behavior.
- Add a win condition, such as finding a treasure or escaping a room.
- Show a clear message when the player wins or loses.
