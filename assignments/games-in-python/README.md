
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic word-guessing game where players guess letters to reveal a hidden word before running out of attempts. You'll practice string manipulation, loops, conditionals, and random selection.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a fully functional Hangman game that manages game state, accepts player input, and displays progress. The game should select a random word from a predefined list and allow players to make letter guesses until they either guess the word or exhaust their attempts.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses from the player
- Display current progress in underscore format (_ _ _)
- Track and display incorrect guesses remaining
- End the game when the word is guessed or attempts are exhausted
- Display appropriate win/lose messages with game outcome
